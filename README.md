# 🌿 বাজার দর | BazarDor

### Your Everyday Market Price Companion 🇧🇩

**BazarDor** is a web application designed to help people in Bangladesh explore the prices of everyday essential commodities in one place. From rice and lentils to vegetables, fish, meat, eggs, and spices, BazarDor makes market price information easier to explore and understand.

🔗 **Live Demo:** [Visit BazarDor](https://bazar-dor-yp8h.vercel.app/)

---

## ✨ Key Features

- 📊 **Market Price Overview** — Explore the prices of essential daily commodities in one convenient place.
- 📈 **Price Change Tracking** — Identify products with rising or falling prices and view their percentage changes.
- 🛒 **Wide Range of Products** — Browse everyday essentials, including rice, lentils, cooking oil, vegetables, fish, meat, eggs, dairy products, and spices.
- 💰 **Price Comparison Insights** — View available average, minimum, and maximum price information to better understand market prices.
- 📱 **User-Friendly Interface** — Enjoy a clean, accessible browsing experience designed to make market information easy to explore.

---

## 🛠️ Technologies Used

- **Next.js** — React framework for building the web application.
- **React** — Component-based user interface development.
- **JavaScript** — Application logic and interactivity.
- **Tailwind CSS** — Responsive styling and modern UI design.
- **Vercel** — Application deployment and hosting.

---

## 🎯 Project Goal

The goal of BazarDor is to make everyday market price information more accessible to people in Bangladesh, helping users explore essential commodity prices and make more informed shopping decisions.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm, or another compatible package manager

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/ShovonDas-Dev/Bazar-Dor.git
```

**2. Navigate to the project directory**

```bash
cd Bazar-Dor
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
